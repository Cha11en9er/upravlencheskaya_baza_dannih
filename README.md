# upravlencheskaya_baza_dannih

Репозиторий для проекта по управленческой базе данных (УБД) для строительных компаний.

## Что здесь

- **`ubd/`** — МВП сайта по ТЗ (`docs/ТЗ от 01.03.docx`): FastAPI + SQLAlchemy +
  Jinja2. Старт и структура — [ubd/README.md](ubd/README.md).
- **`ubd/docs/`** — решения по стеку, установка/переход на PostgreSQL, объём МВП,
  журнал сборки.
- **`roadmap/`** — дневные фиксации работ (`ДД.ММ.ГГ_summary.md`) и постоянные
  заметки (`roadmap/notes/`). Правила ведения — [AGENTS.md](AGENTS.md).
- **`tools/`** — сборка Excel-базы компаний (девелоперы/генподрядчики из Синапс).

## Быстрый старт (локально)

```
run_ubd.bat           → http://127.0.0.1:8000
admin@ubd.local / admin123
```
